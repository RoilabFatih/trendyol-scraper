Trendyol Satıcı Paneli

Satıcı & API Bağlantısı

Bu bilgiler SQLite veritabanına yazılır ve sunucu yeniden başlasa da kalıcıdır (Railway'de bir Volume bağlamadıysanız restart sonrası sıfırlanabilir).

Trendyol satıcı paneli URL'inde geçen `mid` veya `supplierId`.
API çağrısı başına kaç ürün çekileceği (10–1000).
Boş bırakılırsa varsayılan kullanılır.

İş Çalıştırma

"Çalıştır"a bastığınızda önce API üzerinden ürün listesi çekilir, ardından satıcının tüm ürünleri Trendyol storefront'undan taranır. Sonuçlar Veriler sekmesinde görünür.

⚠️ Not: Storefront tarama Trendyol'un Cloudflare WAF'ı tarafından Türkiye dışı veri merkezi IP'lerinden engellenir (HTTP 403). Bu sunucudan sadece API aşaması başarılı olur. Storefront verisini de almak için repodaki run_local.bat ile kendi makinenizden çalıştırın — sonuçlar yine bu panele yüklenir.
